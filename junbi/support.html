Common questions

How do I play against a friend online?

Open “Fight a Friend”. One player creates a match and shares the short code, the other enters it. Both devices need an internet connection.

The friend code does not work.

Check that the code is typed exactly and was created recently. If it still fails, create a new match and share the new code. Switching the network (Wi-Fi or cellular) sometimes helps.

Can I move my progress to another device?

Progress is stored only on the device. There is no account or cloud sync, so it cannot be moved automatically, and deleting the app erases it.

I bought the full game. How do I get it on another device?

Sign in with the same Apple Account, open any locked mode and tap “Restore purchase”.

How do I change the language?

Open Settings in the main menu and choose a language from the list.

How do I report a problem?

Email us your device model, system version and a short description of what happened. A screenshot helps.

What data does the game use? Read the Privacy Policy.
