Junbi

Олимпийское тхэквондо

Junbi — игра про тхэквондо по правилам World Taekwondo: электронные жилеты, три раунда, бойцы из разных стран и реалистичная техника ударов.

  • Чемпионат, мировой рейтинг, тренировка с тренером и быстрый бой
  • Бой с другом по сети по короткому коду
  • Бойцы из разных стран, у каждого своя коронка
  • Без аккаунта, без рекламы, без слежки
