隐私政策

最后更新：2026年11月27日

本政策说明应用 Junbi：奥林匹克跆拳道（Notemia）如何处理你的数据。

简而言之

Junbi 不要求你创建账户。没有广告、没有分析、没有跟踪。Notemia 不收集、不存储、也不出售任何关于你的个人数据。

留在你设备上的内容

你的进度、设置、所选选手、排名和已保存的回放只存储在你的设备上，我们无法查看。删除应用即会删除这些内容。

完整版游戏

Junbi 可免费下载，完整版游戏为一次性 App 内购买。购买由 Apple 通过你的 Apple 账户完成并收费。我们永远看不到你的姓名、Apple 账户或付款信息：App 只从 App Store 得知是否已购买完整版，以便解锁并在你的其他设备上恢复。

Game Center（可选）

如果你已登录 Game Center，游戏会将你的排名积分、胜场数和成就发送到 Apple Game Center，并以你的 Game Center 资料显示在其排行榜和成就中。Apple 按照其自身的隐私政策处理这些数据；Notemia 不会获得你的 Game Center 资料。你可以在设备的设置中关闭 Game Center。

与好友对战（可选）

只有当你选择时才会开始在线游戏。为连接两位玩家，游戏使用 Unity Technologies 提供的 Unity Gaming Services（Authentication 和 Relay）。此时 Unity 会创建匿名玩家 ID、发放短加入代码，并处理 IP 地址等网络数据，以便把你与好友连接起来并在你们的设备之间传递比赛。Notemia 不会接收或存储这些数据。Unity 如何处理这些数据，请见Unity 隐私政策。

如果你从不使用“与好友对战”，以上这些都不会发生。

儿童

Junbi 不会有意收集任何人（包括儿童）的个人信息。游戏中没有聊天、个人资料，也无法分享个人信息。

政策变更

如本政策有变更，新版本将连同新日期发布在此页面。
