隱私權政策

最後更新：2026年11月27日

本政策說明應用程式 Junbi：奧林匹克跆拳道（Notemia）如何處理你的資料。

簡而言之

Junbi 不要求你建立帳號。沒有廣告、沒有分析、沒有追蹤。Notemia 不會收集、儲存或出售任何關於你的個人資料。

留在你裝置上的內容

你的進度、設定、所選選手、排名與已儲存的重播只儲存在你的裝置上，我們無法查看。刪除應用程式即會刪除這些內容。

完整版遊戲

Junbi 可免費下載，完整版遊戲為一次性 App 內購買。購買由 Apple 透過你的 Apple 帳號完成並收費。我們永遠看不到你的姓名、Apple 帳號或付款資訊：App 只從 App Store 得知是否已購買完整版，以便解鎖並在你的其他裝置上恢復。

Game Center（選用）

如果你已登入 Game Center，遊戲會將你的排名積分、勝場數和成就傳送到 Apple Game Center，並以你的 Game Center 個人資料顯示在其排行榜和成就中。Apple 依其自身的隱私權政策處理這些資料；Notemia 不會取得你的 Game Center 個人資料。你可以在裝置的設定中關閉 Game Center。

與好友對戰（選用）

只有在你選擇時才會開始線上遊戲。為連接兩位玩家，遊戲使用 Unity Technologies 提供的 Unity Gaming Services（Authentication 與 Relay）。此時 Unity 會建立匿名玩家 ID、發出短加入代碼，並處理 IP 位址等網路資料，以便把你與好友連線並在你們的裝置之間傳遞比賽。Notemia 不會接收或儲存這些資料。Unity 如何處理這些資料，請見Unity 隱私權政策。

如果你從不使用「與好友對戰」，以上這些都不會發生。

兒童

Junbi 不會刻意蒐集任何人（包括兒童）的個人資訊。遊戲中沒有聊天、個人檔案，也無法分享個人資訊。

政策變更

若本政策有變更，新版本將連同新日期發布於此頁面。
