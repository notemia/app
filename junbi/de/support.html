Häufige Fragen

Wie spiele ich online gegen einen Freund?

Öffnen Sie „Mit Freund“. Ein Spieler erstellt ein Match und teilt den kurzen Code, der andere gibt ihn ein. Beide Geräte brauchen eine Internetverbindung.

Der Freundescode funktioniert nicht.

Prüfen Sie, ob der Code genau eingegeben und erst kürzlich erstellt wurde. Sonst erstellen Sie ein neues Match und teilen den neuen Code. Ein Netzwechsel (WLAN oder Mobilfunk) hilft manchmal.

Kann ich meinen Fortschritt auf ein anderes Gerät übertragen?

Der Fortschritt liegt nur auf dem Gerät. Es gibt weder Konto noch Cloud-Sync, daher ist keine automatische Übertragung möglich; beim Löschen der App wird er gelöscht.

Ich habe das volle Spiel gekauft. Wie bekomme ich es auf ein anderes Gerät?

Melde dich mit demselben Apple Account an, öffne einen gesperrten Modus und tippe auf „Kauf wiederherstellen“.

Wie ändere ich die Sprache?

Öffnen Sie im Hauptmenü die Einstellungen und wählen Sie eine Sprache aus der Liste.

Wie melde ich ein Problem?

Senden Sie uns Gerätemodell, Systemversion und eine kurze Beschreibung. Ein Screenshot hilft.

Welche Daten nutzt das Spiel? Lesen Sie die Datenschutzerklärung.
