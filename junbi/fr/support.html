Questions fréquentes

Comment jouer en ligne contre un ami ?

Ouvrez « Contre un ami ». Un joueur crée un match et partage le code court, l’autre le saisit. Les deux appareils ont besoin d’une connexion internet.

Le code de l’ami ne fonctionne pas.

Vérifiez que le code est saisi exactement et qu’il a été créé récemment. Sinon, créez un nouveau match et partagez le nouveau code. Changer de réseau (Wi-Fi ou mobile) aide parfois.

Puis-je transférer ma progression sur un autre appareil ?

La progression n’est stockée que sur l’appareil. Il n’y a ni compte ni synchronisation cloud : elle ne peut pas être transférée automatiquement et la suppression de l’application l’efface.

J’ai acheté le jeu complet. Comment l’obtenir sur un autre appareil ?

Connectez-vous avec le même compte Apple, ouvrez un mode verrouillé et touchez « Restaurer l’achat ».

Comment changer la langue ?

Ouvrez les réglages dans le menu principal et choisissez une langue dans la liste.

Comment signaler un problème ?

Envoyez-nous le modèle de votre appareil, la version du système et une courte description. Une capture d’écran aide.

Quelles données le jeu utilise-t-il ? Lisez la politique de confidentialité.
